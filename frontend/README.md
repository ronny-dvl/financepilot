# FinancePilot Web

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # gera a pasta dist/ (estática, pode subir na Vercel/Netlify)
```

Rotas: `/` landing, `/analisar` (upload do PDF), `/dashboard`.
Ajuste cores e fonte em `src/styles/tokens.css` com os valores do Dev Mode do Figma.
